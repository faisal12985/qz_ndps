# New Dreams Public School website

This is a static website. Public page content and images are maintained directly in the HTML, CSS, JavaScript, and image files in this project.

## Local preview

Run a static HTTP server from the project directory, for example:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000/`.

This project has no server-side content editing or online admission submission; update public content and image references directly in the project files.
